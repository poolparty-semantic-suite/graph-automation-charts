# Graphwise Graph Automation Helm Charts

Official Helm charts for installing [Graph Automation](https://graphwise.ai/components/graph-automation/) in Kubernetes.

The repository can be added with the following command:

```shell
helm repo add graphwise-graph-automation https://poolparty-semantic-suite.github.io/graph-automation-charts
```
